# Grow My Therapy — Stage 2 Assignment

## Run locally
1. Install Node.js 18+ (20 LTS recommended).
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open http://localhost:3000.

## Deploy to Vercel
1. Create a public GitHub repository.
2. Push this project to GitHub.
3. Import the repo at Vercel.
4. Framework: Next.js. Build command: `npm run build`.
5. Deploy and copy the live URL.
